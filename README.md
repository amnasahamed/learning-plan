# 🚀 30-Day AI Systems Builder - Learning Plan

This repository contains a comprehensive 30-day learning plan to transform from automation beginner to AI systems architect, **plus a complete Learning Management System (LMS)** to track your progress!

### 📚 Learning Content

- **[ai-builder-lms/](./ai-builder-lms/)** - Full-featured web application for learning
  - Progress tracking
  - Note-taking
  - Code examples with syntax highlighting

  - Docker deployment ready (Port 737)
  - **[Quick Start Guide](./ai-builder-lms/QUICKSTART.md)**

## 🎯 Course Overview

- **Duration**: 30 days
- **Time**: 30 min/day (or 3-4 hours/week)
- **Format**: Learn → Apply → Build → Ship
- **Tools**: n8n, JavaScript, Python, AI APIs

## 🗺️ Learning Path

### Week 1: JavaScript for Automations
Build data transformation workflows with confidence

### Week 2: APIs and Logic Flow
Master external API integration and error handling

### Week 3: Smart Agents & AI APIs
Create context-aware AI agents with memory

### Week 4: Python & System Architecture
Design and deploy production RAG systems

## 🏁 Getting Started

### Option 1: Use the Interactive LMS (Recommended)

```bash

docker-compose up -d
```

## 🚀 Deployment Options

### Local Development
```bash
cd ai-builder-lms
npm install
npm run dev
# Visit http://localhost:737
```

### Docker (Production)
```bash
cd ai-builder-lms
docker-compose up -d
# Visit http://localhost:737
```
